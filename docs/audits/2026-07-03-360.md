# 360-Degree Audit — 2026-07-03

Full code review, structural audit, and 360-degree analysis of the
`sensor_app` full-stack demo (Flask + Postgres backend, Angular frontend,
Grafana, Docker Compose, live on Render), performed with the methodology in
[solid-ai-templates](https://github.com/braboj/solid-ai-templates)
(`templates/base/workflow/360.md`).

Run as **seven parallel, context-isolated reviewers**, each starting with a
clean context and a single role prompt to prevent perspective bleed. Because
this app has a real user-facing surface, the three non-engineering lenses
(Value, Viability, Discovery) are kept, and the engineer "Quality" lens is
re-projected into four engineering dimensions (Backend code, Architecture &
Structure, Frontend code, Testing/CI) — mirroring the
[2026-06-26 baseline audit](2026-06-26-360.md) so the before/after is directly
comparable. The overall grade is the lowest dimension grade. Every crux finding
was independently re-verified by the parent agent (`git ls-files`, file reads,
`grep`, and live tool runs — `pytest`, `mypy`, `ruff`, `npm test`) before
grading.

This is a **milestone re-audit** after the epic-#12 refactor. The baseline
graded the pre-refactor MVP overall **D** (101 findings, 2 Critical). This run
grades the current `main` (`d4e29c6`).

## Current bottleneck

**Testing, Tooling & CI/CD (B-)** — the quality-gate stack is now genuinely
functional (backend pytest **35/35**, frontend Karma **22/22**, `mypy --strict`
clean, CI green on `main`), a night-and-day reversal of the baseline's *zero*
CI. What holds it below A-territory is **test fidelity against the project's own
conventions**: tests substitute `sqlite:///:memory:` for the mandated real
PostgreSQL test DB (CLAUDE.md §3.1 expressly forbids SQLite substitution), there
is no `conftest.py`/`TestingConfig` fixture (each `TestCase` rolls its own config
dict), backend coverage is entirely unmeasured (no `pytest-cov`), `ruff format`
fails on 12/16 source files with no format gate in CI or pre-commit, and the
Layer-1 `.editorconfig` is missing. None of these affect the running app; all are
gaps against the stated standard.

## Cross-cutting themes

1. **Test-fidelity gap (the bottleneck).** SQLite-in-memory substituted for
   Postgres, no `conftest.py`/`TestingConfig` fixture, and no backend coverage
   measurement. A single theme — tests don't yet meet the conventions in
   CLAUDE.md §3.1 — accounts for both open High findings. The suites pass and are
   deterministic; they simply run against the wrong engine with duplicated setup.

2. **Format & editor-gate hole.** Lint (`ruff check`, eslint), type (`mypy
   --strict`), and test gates are all wired and green, but the **format** layer
   has a hole: `ruff format --check` reports 12/16 files would reformat, and
   neither CI (`ruff check .` only) nor `.pre-commit-config.yaml` (`ruff-check`
   only) enforces it. The Layer-1 `.editorconfig` (CLAUDE.md §3.2) is also
   absent.

3. **Residual tutorial scaffolding (thin tail).** The baseline's dominant
   "tutorial-scaffold debt" theme is ~95% cleared (`.tutorial/`, `db.json`,
   dead deps, identity leftovers all gone), but two artefacts survived:
   `provideProtractorTestingSupport()` in `frontend/src/main.ts` (the *exact
   line* the baseline flagged as FE#13, shipped into every prod bundle) and an
   unreferenced `frontend/src/assets/angular.svg`.

4. **Visual proof-of-product.** The only thing keeping Discovery out of
   A-range: no dashboard screenshot or GIF anywhere in the README, and no custom
   Open Graph image, so both the landing page and any shared link ask the viewer
   to imagine the product (or cold-start the live site) instead of showing it.

5. **Free-tier operational tail.** Demo-acceptable but real if promoted: Render
   free Postgres expires on a timer with manual-only backup/DR (no automated
   job), a SQLite `DATABASE_URL` fallback in `ProductionConfig`, and an
   empty SSR shell on first paint before Angular hydrates.

A reassuring counter-note: **both baseline Criticals are resolved and verified
at the history level.** The Werkzeug-debugger RCE (debug server as the Docker
CMD) is replaced by a gunicorn entrypoint with `debug` gated off by default; the
151 MB `frontend.zip` is absent from tracked files, the working tree, *and*
reachable git history (0 references, no blob > 1 MB), and the 322 MB
`frontend/.tutorial/` second app is gone. The tracked tree shrank from ~473 MB to
**4.8 MB**. The shipped product delivers on every user-facing promise, live on
Render.
